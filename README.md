# 💬 شات معا

تطبيق دردشة فورية باللغة العربية، مبني بـ Node.js + Express + WebSocket + PostgreSQL.

## المتطلبات
- Node.js 18 أو أحدث
- قاعدة بيانات PostgreSQL (محلية أو مستضافة مجاناً مثل Neon / Railway / Supabase)

## خطوات التشغيل

1. **تثبيت الاعتماديات**
   ```bash
   npm install
   ```

2. **إعداد ملف البيئة**
   انسخ `.env.example` إلى `.env` وعدّل القيم:
   ```bash
   cp .env.example .env
   ```
   - `DATABASE_URL`: رابط الاتصال بقاعدة بيانات PostgreSQL
   - `JWT_SECRET`: أي نص سري عشوائي طويل
   - `ADMIN_PASSWORD`: كلمة مرور دخول لوحة التحكم (افتراضياً `omar_root`)

3. **تهيئة قاعدة البيانات** (ينشئ كل الجداول تلقائياً)
   ```bash
   npm run init-db
   ```

4. **تشغيل الخادم**
   ```bash
   npm start
   ```
   الموقع يعمل افتراضياً على: `http://localhost:3000`

## الصفحات
- `/` أو `/index.html` — تسجيل الدخول وإنشاء حساب
- `/chat.html` — الدردشة العامة (تتطلب تسجيل دخول)
- `/admin.html` — لوحة تحكم الإدارة (كلمة المرور: `omar_root` أو ما حددته في `.env`)

## الميزات المنفذة
- تسجيل برقم هاتف بصيغة 963 + تفعيل تلقائي
- تشفير كلمات المرور (bcrypt) وتوكن دخول (JWT)
- دردشة عامة فورية عبر WebSocket + مؤشر "يكتب الآن" + حالة اتصال
- رسائل خاصة بين الأعضاء + ميزة "إشارة انتباه" (poke)
- غرف خاصة بكلمة مرور (REST API جاهزة، الواجهة الأساسية للدردشة العامة)
- لوحة تحكم كاملة: حظر/فك حظر/حذف/تعديل اسم/ترقية لمشرف بصلاحيات محددة/إنذارات
- كلمات ممنوعة تُفلتر تلقائياً من كل رسالة
- شريط إعلانات متحرك يُتحكم به بالكامل من لوحة التحكم (سرعة، اتجاه، حجم خط، ألوان، إظهار/إخفاء)
- وضع صيانة يُغلق الدردشة للأعضاء مع رسالة وسبب وموعد عودة
- رسائل الأعضاء إلى الإدارة + سجل كامل لكل إجراءات الإدارة (Audit Log)
- حماية أساسية: رفض روابط/أنماط مشبوهة، فلترة محتوى الرسائل
- تصميم عربي (RTL) متجاوب للجوال والكمبيوتر
- قاعدة بيانات PostgreSQL كاملة (9 جداول)

## 🚀 النشر المجاني الدائم (Render + Neon)

### الخطوة 1: إنشاء قاعدة بيانات على Neon
1. سجّل حساب مجاني في [neon.tech](https://neon.tech) (بدون بطاقة ائتمان)
2. أنشئ مشروع جديد (Project) — سيولّد لك قاعدة PostgreSQL تلقائياً
3. من لوحة Neon، انسخ **Connection String** (يبدأ بـ `postgres://...`)

### الخطوة 2: رفع المشروع على GitHub
1. أنشئ مستودع جديد على GitHub
2. ارفع محتويات هذا المشروع إليه (فك الضغط أولاً ثم `git push`)

### الخطوة 3: النشر على Render
1. سجّل حساب مجاني في [render.com](https://render.com) (بدون بطاقة ائتمان)
2. اضغط **New → Blueprint**، واختر مستودع GitHub الذي رفعته
3. Render سيقرأ ملف `render.yaml` تلقائياً ويجهز كل الإعدادات
4. عند سؤالك عن `DATABASE_URL`، الصق رابط Neon الذي نسخته في الخطوة 1
5. اضغط **Apply** — سيبدأ البناء والنشر تلقائياً (يستغرق دقائق)

### الخطوة 4: تهيئة الجداول (مرة واحدة فقط)
من تبويب **Shell** داخل خدمتك على Render، نفّذ:
```bash
npm run init-db
```

### الخطوة 5: جاهز! 🎉
افتح الرابط الذي يعطيك إياه Render (مثل `https://chat-maa.onrender.com`) — موقعك يعمل الآن بشكل دائم ومجاني.

> ملاحظة: كلمة مرور لوحة التحكم هي `omar_root` (يمكن تغييرها من متغير `ADMIN_PASSWORD` في إعدادات Render).
> ملاحظة: الخدمة المجانية تنام بعد 15 دقيقة خمول وتستيقظ خلال ~دقيقة عند أول زيارة — هذا طبيعي في الخطة المجانية.
